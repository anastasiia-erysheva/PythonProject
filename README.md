# 🇹🇷 Turkish A2 Assistant Bot & Python Practice

Репозиторий проекта, объединяющий разработку Telegram-бота для изучения турецкого языка (уровень A2) и решение практических задач по Python.

## 📌 Описание Telegram-бота
Бот помогает структурированно осваивать грамматику турецкого языка уровня A2, разбирать жизненные примеры и выполнять интерактивные задания прямо в Telegram.

### Основной функционал:
* 📘 **Урок дня (A2):** случайный выдача грамматических правил (деепричастия `-ıp/ -ip`, конструкции времени `-dığı zaman`, долженствование `-malı / -meli` и др.).
* 💬 **Примеры и практика:** разбор реальных фраз с интерактивными заданиями.
* ⌨️ **Удобная клавиатура:** `ReplyKeyboardMarkup` для быстрого доступа к материалам.

---

## 🛠 Технологии
* **Python 3.12**
* **pyTelegramBotAPI (`telebot`)** — работа с Telegram Bot API
* **python-dotenv** — безопасная работа с переменными окружения
